# Summarize — AI PDF Summarizer

# How to install

# Create the virtual environment

python -m venv venv

# On macOS / Linux:

source venv/bin/activate

# On Windows (Command Prompt):

venv\Scripts\activate

# On Windows (PowerShell):

venv\Scripts\Activate.ps1

## Step 5 — Install dependencies

pip install -r requirements.txt

## Step 6 — Run the app

python app.py

## Step 7 — Open in your browser

Visit: **[http://localhost:5000](http://localhost:5000)**

## How to use

1. **Drag** a PDF onto the upload box, or **click** it to browse your files
2. Pick a **summary length** (Short / Medium / Detailed)
3. Click **Summarize PDF**
4. Wait 5–15 seconds while Gemini reads your document
5. Read, scroll, and **Copy** the summary if needed
6. Click **Summarize Another PDF** to start over
